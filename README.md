## 🎯 معرفی

**HostVDS Telegram Bot** یک راه‌حل جامع و متن‌باز برای ارائه‌دهندگان خدمات VPS است که می‌خواهند از طریق ربات تلگرام به کاربران خود سرور مجازی بفروشند. این سیستم با استفاده از **OpenStack API** به HostVDS متصل شده و امکان فروش ساعتی VPS را با کمترین دخالت دستی فراهم می‌کند.

### ✨ چرا این پروژه؟

- 💰 **فروش ساعتی** - کسب درآمد از هر دقیقه استفاده کاربر
- 🤖 **کاملاً خودکار** - از ثبت سفارش تا تحویل سرور
- 🔐 **امن** - رمزهای قوی و منحصر به فرد برای هر سرور
- ⚡ **سریع** - تحویل سرور در کمتر از ۳۰ ثانیه
- 🎛️ **پنل مدیریت** - کنترل کامل از طریق ربات
